第一章 LINUX基本使用方法

LINUX是什么

LINUX是一套类UNIX的操作系统，来源于UNIX，开源，由Linus Torvalds于1991年开始开发

UNIX是一套多用户，多任务操作系统，由1969年在AT&T的贝尔实验室开发。

UNIX不仅是一个OS，更具有独特的设计哲学和美学，简洁至上（KISS原则，Keep It Simple, Stupid）,提供机制而非策略。

LINUX具有完整的操作系统组合集合

​ 内核+GNU工具链+图形系统+应用软件

​ 遵循POSIX标准，保持与UNIX兼容性

模块性架构设计

​ 可定制性：内核模块动态加载/卸载

​ 支持多种硬件架构：X86，ARM，RISC-V等

生态系统特征

​ 开源协作开发模式

​ 超过27000名贡献者

​ 每2-3个月发布新内核版本

What is the Linux Kernel?

​ 操作系统的核心组件，硬件与应用程序间的抽象层，约2800万行代码，

​ 关键特性：单体内核设计、模块化机制、强占式多任务、对称多处理（SMP）支持

一、进程管理（Process Management）

  1. 进程调度（CFS调度器）
    • 作用：通过完全公平调度器（Completely Fair Scheduler）动态分配CPU时间片，确保多任务的高效、公平执行。
    • 特点：基于红黑树实现，优先处理交互式进程（如GUI应用），避免“饥饿”现象。
  2. 命名空间隔离（Namespace Isolation）
    • 作用：实现轻量级虚拟化（如Docker容器），隔离进程的视图（如PID、网络、文件系统等）。
    • 示例：每个容器拥有独立的进程ID空间（PID namespace）。
  3. 权限控制（Capabilities）
    • 作用：细化传统“root超级用户”权限，将特权拆分为30+种能力（如 CAP_NET_ADMIN 仅控制网络配置），提升安全性。

二、内存管理（Memory Management）

  1. 虚拟内存系统
    • 作用：通过分页（Paging）和地址转换，让进程“认为”独占内存，实际物理内存由内核动态分配。
    • 关键技术：
      • 写时复制（Copy-on-Write）优化进程创建。
      • 内存映射（mmap）加速文件访问。
  2. 交换空间管理（Swap Space）
    • 作用：将不活跃的内存页写入磁盘（如 /swapfile），避免物理内存耗尽导致系统崩溃。
    • 注意：过度使用交换空间会显著降低性能（磁盘I/O慢）。

三、设备驱动（Device Drivers）

  1. 统一设备模型（Unified Device Model）
    • 作用：通过 sysfs（/sys 目录）统一表示设备树，驱动开发遵循标准接口（如 udev 动态管理设备节点）。
  2. 热插拔支持（Hotplug）
    • 示例：插入U盘时，内核自动加载驱动并创建 /dev/sdb1 设备文件。
  3. DMA管理（Direct Memory Access）
    • 作用：允许外设（如磁盘、网卡）直接读写内存，减少CPU负担，提升I/O性能。

四、文件系统（File System）

  1. VFS抽象层（Virtual File System）
    • 作用：为上层应用提供统一接口（如 open()、read()），底层支持100+文件系统类型（如EXT4、XFS、NTFS）。
    • 关键结构：inode 描述文件元数据，dentry 缓存目录项。
  2. 支持多种文件系统类型
    • 扩展性：内核模块化设计，可动态加载文件系统驱动（如 modprobe nfs）。

五、网络支持（Networking）

  • 网络协议栈
    • 分层处理：从物理层（网卡驱动）到应用层（如HTTP），支持TCP/IP、UDP、ICMP等协议。
    • 性能优化：零拷贝（Zero-copy）技术减少数据复制开销。

Linux采用宏内核（monolithic kernel）

glibc的作用：glibc是用户空间的C标准库，封装系统调用并提供高级API（如内存分配 malloc()），简化应用程序开发。

VFS如何实现文件系统抽象：

  1. 定义统一的文件操作接口（如 file_operations）。
  2. 每种文件系统实现自己的接口函数（如 ext4_read()）。
  3. VFS根据挂载的文件系统类型调用对应的函数，对用户透明。

功能组件列表

  • The Bootloader (启动引导程序)
  • The kernel (内核)
  • Daemons (后台服务)
  • The Shell (外壳)
  • The Libraries (各种运行库，如glibc，或开发环境)
  • The GUI environment (GNOME, KDE桌面环境)
  • Applications (应用程序)

主要目录定义

一、系统关键目录

  1. /bin
    • 作用：存放基础命令的二进制文件（如 ls、cp 等），所有用户均可使用。
    • 注意：现代系统中可能与 /usr/bin 合并（通过符号链接）。

  2. /boot
    • 作用：包含引导加载器（如 GRUB）的静态文件和内核镜像，系统启动依赖此目录。

  3. /dev
    • 作用：设备文件的虚拟目录（如 /dev/sda 表示磁盘，/dev/tty 表示终端），由内核动态生成。

  4. /etc
    • 作用：存放主机特定的系统配置（如网络配置、软件配置等），多为文本文件。

  5. /lib
    • 作用：存储基础共享库（如 .so 文件）和内核模块，/bin 和 /sbin 中的命令依赖这些库。

  6. /sbin
    • 作用：存放系统管理命令的二进制文件（如 fdisk、ifconfig），通常需超级用户权限。

二、挂载点相关目录

  1. /media
    • 作用：自动挂载可插拔介质（如 U 盘、光盘）的默认位置。

  2. /mnt
    • 作用：临时手动挂载文件系统的目录（如网络存储或额外分区）。

三、用户与数据目录

  1. /home
    • 作用：普通用户的主目录，每个用户拥有独立子目录（如 /home/user1）。

  2. /root
    • 作用：超级用户（root）的主目录，与普通用户的 /home 分离。

  3. /opt
    • 作用：存放第三方附加软件包（如大型商业软件），通常每个软件有独立子目录。

  4. /srv（图中误写为 “served”）
    • 作用：存储系统服务提供的数据（如 Web 服务的网站文件、FTP 的文件）。

四、运行时与临时目录

  1. /tmp
    • 作用：存放临时文件，系统重启后可能清空。

  2. /var
    • 作用：存储频繁变化的变量数据（如日志 /var/log、缓存 /var/cache、邮件 /var/mail）。

五、层次结构目录

• /usr • 作用：类似 Windows 的 “Program Files”，包含用户级程序、库和文档，子目录如：
◦ /usr/bin：用户命令
◦ /usr/lib：用户级库文件
◦ /usr/local：本地编译的软件

问题：如何将hello.c设置为所有者可读写、组可读、其他无权限？权限值计算：

  • 用户：rw- = 4+2+0 = 6
  • 组：r-- = 4+0+0 = 4
  • 其他：--- = 0+0+0 = 0
  1. 执行命令：
chmod 640 hello.c

eg:

# 初始状态
-rw-rw-r-- 1 ubuntu Users 74 Oct 21 04:37 hello.c

# 1. 修改文件所有者
chown tester hello.c
# 结果：
-rw-rw-r-- 1 tester Users 74 Oct 21 04:37 hello.c

# 2. 修改文件所属组
chgrp Testers hello.c
# 结果：
-rw-rw-r-- 1 tester Testers 74 Oct 21 04:37 hello.c

# 3. 移除组的读写权限
chmod g-rw hello.c
# 结果：
-rw----r-- 1 tester Testers 74 Oct 21 04:37 hello.c

# 4. 使用数字模式设置权限
chmod 644 hello.c
# 最终结果：
-rw-r--r-- 1 tester Testers 74 Oct 21 04:37 hello.c

-maxdepth（搜索深度） find . -maxdepth 3 -type f 最多搜索3层子目录
查找后处理 -delete 无 find . -name "*.tmp" -delete 删除所有.tmp文件
-exec 接后续操作命令 find . -user root -exec chown alice {} \; 将root属主的文件改为alice所有
+（合并结果） find . -name "*.txt" -exec cat {} + > all.txt 合并所有.txt文件内容到all.txt

SHELL编程

Shell 脚本是 Linux/Unix 系统管理和自动化的重要工具。下面我将从基础到高级全面介绍 Shell 编程的核心内容。

一、Shell 脚本基础

1. 创建和执行脚本

#!/bin/bash
# 这是一个注释
echo "Hello World!"

• 第一行 #!/bin/bash 称为 shebang，指定解释器 • 给脚本添加执行权限：chmod +x script.sh • 执行方式： • ./script.sh • bash script.sh • source script.sh (在当前shell执行)

2. 变量

name="John"      # 定义变量
echo $name       # 使用变量
echo ${name}     # 更安全的引用方式
readonly var=10  # 只读变量
unset var        # 删除变量

特殊变量： • $0 脚本名称 • $1-$9 位置参数 • $# 参数个数 • $* 所有参数 • $? 上条命令退出状态 • $$ 当前进程PID

二、字符串操作

str="hello world"
echo ${#str}        # 字符串长度
echo ${str:0:5}     # 子串(hello)
echo ${str/world/universe}  # 替换
echo ${str#h* }     # 删除前缀(world)
echo ${str%w*}      # 删除后缀(hello )

三、数组

arr=("a" "b" "c")   # 定义数组
echo ${arr[1]}      # 访问元素(b)
echo ${arr[@]}      # 所有元素
echo ${#arr[@]}     # 数组长度
arr+=(d)            # 添加元素
unset arr[1]        # 删除元素

四、条件判断

1. if 语句

if [ condition ]; then
  commands
elif [ condition ]; then
  commands
else
  commands
fi

2. test 命令和 [ ]

# 数值比较
[ $a -eq $b ]  # 等于
[ $a -ne $b ]  # 不等于
[ $a -gt $b ]  # 大于
[ $a -lt $b ]  # 小于

# 字符串比较
[ "$str1" = "$str2" ]
[ "$str1" != "$str2" ]
[ -z "$str" ]  # 空字符串
[ -n "$str" ]  # 非空字符串

# 文件测试
[ -f "file" ]  # 是普通文件
[ -d "dir" ]   # 是目录
[ -e "path" ]  # 存在
[ -r "file" ]  # 可读
[ -w "file" ]  # 可写
[ -x "file" ]  # 可执行

3. case 语句

case $var in
  pattern1)
    commands ;;
  pattern2)
    commands ;;
  *)
    default commands ;;
esac

五、循环结构

1. for 循环

for var in list; do
  commands
done

# C风格for循环
for ((i=0; i<10; i++)); do
  echo $i
done

2. while 循环

while [ condition ]; do
  commands
done

# 无限循环
while true; do
  commands
done

3. until 循环

until [ condition ]; do
  commands
done

4. 循环控制

break     # 退出循环
continue  # 跳过本次循环

六、函数

function_name() {
  commands
  [return value]
}

# 调用函数
function_name arg1 arg2

# 获取返回值
ret=$?

return 返回，如果不加，将以最后一条命令运行结果，作为返回值。

七、输入输出

1. 基本I/O

echo "text"          # 输出
