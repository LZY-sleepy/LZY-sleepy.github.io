状态压缩 (State Compression)

1. 引言

​ 状态压缩是一种常见的优化技术，通常应用于动态规划（DP）问题，尤其是在求解图论问题和优化问题时。通过将状态信息压缩到较小的数据结构中，状态压缩能够减少内存使用并提高算法效率。在很多问题中，状态可以通过一个整数或二进制位数组来表示，减少了空间复杂度，并加速了状态的更新和搜索。

2. 状态压缩的基本概念

​ 状态压缩是通过将多个状态信息编码成一个更小的数据结构（通常是整数），来节省空间的技术。在图论、路径搜索以及优化问题中，通常需要维护大量的状态。通过位运算（尤其是位掩码），可以将这些状态压缩成一个整数，从而高效地存储和操作。

2.1. 位掩码（Bit Masking）

​ 位掩码是一种通过位操作来表示状态的技巧。每个状态对应一个二进制位，使用这些位来表示某个状态的属性。例如，在一个图中，每个节点的访问情况可以通过一个二进制数来表示，其中 1 表示已访问，0 表示未访问。

​ 对于 n 个节点，我们可以使用一个大小为 2^n 的整数来表示所有可能的访问状态。这种方法尤其适用于 旅行商问题（TSP） 和类似问题。

3. 状态压缩的应用

3.1. 旅行商问题（TSP）

旅行商问题是一个经典的最优化问题，要求一个旅行商从多个城市出发，访问每个城市一次并且仅访问一次，最终返回到起点。在解决该问题时，状态压缩可以大大降低内存消耗并提高计算效率。

3.2. 动态规划中的状态压缩

在动态规划中，通常有很多不同的状态需要维护，特别是当涉及到多个子问题时。状态压缩通过使用位掩码来表示子问题的状态，能够显著减少内存的使用。例如，假设我们有 n 个节点，表示访问状态的二进制数的每一位表示一个节点的访问情况。这样，通过位操作，可以有效地跟踪哪些节点已经访问。

3.2.1. 示例：旅行商问题（TSP）的动态规划

对于旅行商问题的动态规划，我们定义 dp[mask][i] 来表示从起始节点出发，访问了 mask 中指定的节点，最后停留在节点 i 时的最短路径长度。

  • mask 是一个二进制数，表示已访问节点的集合。
  • i 是当前节点。

使用状态压缩后，dp 数组的大小为 2^n * n，其中 n 是节点的数量。每次更新 dp 值时，都会通过位运算更新访问状态。


int n = 4; // 4个节点
vector<vector<int>> dp(1 << n, vector<int>(n, INT_MAX));
dp[1][0] = 0; // 从节点0出发，初始状态

for (int mask = 0; mask < (1 << n); ++mask) {
    for (int u = 0; u < n; ++u) {
        if (mask & (1 << u)) { // 如果u节点已经访问过
            for (int v = 0; v < n; ++v) {
                if (!(mask & (1 << v))) { // 如果v节点未访问
                    dp[mask | (1 << v)][v] = min(dp[mask | (1 << v)][v], dp[mask][u] + dist[u][v]);
                }
            }
        }
    }
}

3.2.2 示例：访问所有节点的最短路径问题

存在一个由 n 个节点组成的无向连通图，图中的节点按从 0 到 n - 1 编号。给你一个数组 graph 表示这个图。其中，graph[i] 是一个列表，由所有与节点 i直接相连的节点组成。返回能够访问所有节点的最短路径的长度。你可以在任一节点开始和停止，也可以多次重访节点，并且可以重用边。


class Solution {
public:
    int shortestPathLength(vector<vector<int>>& graph) {
        int n=graph.size();
        queue<tuple<int,int,int>> q;
        vector<vector<int>> assist(n,vector<int>(1<<n));
        for(int i=0;i<n;i++){
            q.emplace(i,1<<i,0);
            assist[i][1<<i]=true;
        }
        int ans=0;
        while(!q.empty()){
            auto [u,mask,dist]=q.front();
            q.pop();
            if(mask==(1<<n)-1){
                ans=dist;
                break;
            }
            for(int v:graph[u]){
                int mask_new=mask | (1<<v);
                if(!assist[v][mask_new]){
                    q.emplace(v,mask_new,dist+1);
                    assist[v][mask_new]=true;
                }
            }
        }
        return ans;
    }
};

3.3. 位操作

位操作（例如按位与 &，按位或 |，按位异或 ^）常常用来修改或检查二进制掩码中的特定位。这些操作通常比其他方法（如数组索引）更高效。

3.3.1. 按位与操作 (&)

​ 用来检查某一位是否为 1，如果该位是 1，则结果为 1，否则为 0。

3.3.2. 按位或操作 (|)

​ 用来将某一位设置为 1，即使其他位保持不变。

3.3.3. 按位异或操作 (^)

​ 用来切换某一位的值。如果该位是 1，则将其变为 0，反之亦然。
